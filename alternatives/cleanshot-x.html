Free CleanShot X alternative: CleanShotXIsDead

Last reviewed October 26, 2026 · License: Apache-2.0 · Source on GitHub

CleanShotXIsDead is a free, open-source screenshot and screen recording app for the Mac, modeled on CleanShot X. It covers area, window, full-screen and scrolling captures, text recognition, MP4 and GIF recording, an annotation editor and shareable links, without a license key or account.

What CleanShot X does, and what CleanShotXIsDead covers

CleanShot X replaces the built-in macOS screenshot tool with a faster, more capable one. After each capture a small overlay lets you copy, save, annotate, pin or upload it. It adds scrolling capture for long pages, OCR to grab text from anything on screen, screen recording to video or GIF, an editor for arrows, blur and numbered steps, background "beautify" options, and CleanShot Cloud for instant links.

CleanShotXIsDead is a native Swift menu-bar app that follows the same structure. Capture modes include All-In-One, Area, Fullscreen, Window, Scrolling (with auto-scroll) and Self-Timer, plus a text capture that copies recognized text using Apple's Vision framework. Window captures can keep the shadow and sit on your wallpaper or a transparent background, and desktop icons can be hidden while you capture.

The Quick Access Overlay appears after each shot. From there, the annotation editor offers arrows, shapes, text, counters, pixelate, highlight, crop and backgrounds, and it can remove the background from a subject using Apple's on-device segmentation. Screen recordings save as MP4 or GIF, with optional click highlights, a keystroke overlay, microphone and computer audio. You can pin a capture so it floats above other windows, and scroll back through Capture History. Uploads go to the project's web app as an anonymous guest and give you a link.

What it costs

As of October 2026, CleanShot's pricing page lists Basic as a one-time $35 purchase with one year of updates and 1 GB of cloud storage; renewing updates costs $19 a year. CleanShot Pro is $10 per user per month billed annually and adds unlimited cloud storage under a fair-use policy, plus team features.

CleanShotXIsDead is free, including updates and share links. CleanShot X Basic is already modestly priced and you keep using it after updates lapse, so the main savings come from avoiding update renewals and the Pro subscription.

How to switch from CleanShot X

  1. Check your Mac runs macOS 14.2 or later. The release is a universal build for Apple silicon and Intel.
  2. Download the signed, notarized DMG from the project page and drag the app into Applications. Quit CleanShot X so the two apps don't compete for the same shortcuts.
  3. Grant Screen Recording when macOS asks. Scrolling capture and the keystroke overlay also ask for Accessibility access.
  4. The default shortcuts use ⌘⇧ with number keys (for example ⌘⇧4 for Area and ⌘⇧5 for All-In-One). If macOS's own screenshot tool still responds, turn off its shortcuts under System Settings → Keyboard → Keyboard Shortcuts → Screenshots, or rebind them in the app.
  5. Go through Settings to match your old setup: save location, overlay behavior, Retina scaling, recording format and what happens after upload. Settings can't be imported from CleanShot X.

Running it yourself

The Mac app is in mac/: ./scripts/run-dev.sh builds a signed development copy and launches it, and swift build and swift test work as usual. The capture engine, selection overlay and editor are adapted from an Apache-2.0 project by the same author. The repository root is a Next.js app that serves the marketing page, a browser-based capture and annotation tool at /app, and the share pages the Mac app links to; run it with npm install and npm run dev. The upload address is a setting in the Mac app, so you can point it at your own deployment.

Limitations

  • Mac only for native capture. The browser version lacks scrolling capture, OCR and GIF export.
  • No video trimming or editing after a recording.
  • Share links are public to anyone who has them, and there are no team spaces, custom domains or branding.
  • The app sends anonymous usage events. Unlike the project's other Mac apps, the current code doesn't include a switch for this in Settings.
  • Default shortcuts overlap with the built-in macOS screenshot keys, so expect a little setup.

FAQ

Is there a browser version?

Yes. The web app captures a screen or tab through the browser's share picker and offers the annotation tools, backgrounds, PNG download and share links, with your library kept in browser storage.

Do captures get uploaded automatically?

Only if you turn that on. By default you choose when to upload from the overlay or editor.

Does OCR send my screen anywhere?

No. Text recognition uses Apple's Vision framework on your Mac.

Can I record GIFs?

Yes. Pick GIF in the pre-record bar, and adjust frame rate and quality in Settings.

Do I need a license key?

No. There's no license, account or trial period.
