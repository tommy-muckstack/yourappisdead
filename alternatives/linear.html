Free Linear alternative: LinearIsDead

Last reviewed October 26, 2026 · License: Apache-2.0 · Source on GitHub

LinearIsDead is a free, open-source issue tracker built around the keyboard, with issues, sub-issues, cycles, projects, triage, saved views and a command menu. It is a faithful single-user take on Linear's workflow. Data is kept in your browser, so it doesn't yet give a team one shared workspace.

What Linear does, and what LinearIsDead covers

Linear is an issue tracker for software teams. Issues belong to teams, move through statuses, and get grouped into time-boxed cycles and longer-running projects and initiatives. It is known for speed and keyboard shortcuts, and paid plans add integrations with GitHub and Slack, insights, SLAs, AI features and admin controls.

LinearIsDead copies the parts that shape daily work. Press C to create an issue, and use quick-create syntax such as !urgent @me #bug +project ~3 to set priority, assignee, label, project and estimate in one line. Issues can have labels, an estimate, a due date and a parent, and sub-issues show progress on the parent. Every change goes into an activity log next to the comments, and ⌘Z undoes.

Navigation follows Linear's layout: Inbox, My issues (Assigned, Created, Subscribed, Activity), Triage (accept, decline or mark duplicate with 1, 2, 3), Initiatives, Projects, a Roadmap timeline, saved Views, and per-team Active, Backlog, All issues and Cycles pages. Cycles include a burn-up chart and a one-click roll-over of unfinished work. You can show issues as a list or a board, group and sub-group them, choose ordering and visible properties, and save the result as a view. J/K, X to multi-select, single-key property setters, G-then-key navigation, ⌘K and a ? shortcut sheet keep your hands on the keyboard.

What it costs

As of October 2026, Linear's pricing page lists Free, Basic at $10 per user per month and Business at $16 per user per month (both billed yearly), and Enterprise with custom annual pricing. The Free plan allows unlimited members but caps you at 250 issues and two teams, with uploads up to 10 MB per file.

LinearIsDead is free at yourappisdead.com/linearisdead, with no issue or team caps in the app. You can use it as a guest without an account. If you run it yourself, you pay only for hosting, and because the workspace lives in the browser, the server mainly serves pages and handles sign-in.

How to switch from Linear

  1. In Linear, export your issues to CSV from the workspace's import and export settings, and keep the file as a record.
  2. Open LinearIsDead. The first visit runs a short setup: workspace name and URL, your first team and its identifier (so issues become, say, ENG-1), and teammates' names.
  3. Choose an empty workspace, then set the team's cycle length, estimate scale and whether triage is on in team settings.
  4. Create labels and projects, then re-enter the open issues you still need. Quick-create syntax makes this faster than filling in each field.
  5. Set up the saved views your team used, with the same grouping and filters.
  6. Back up regularly from Settings › Import / export. The JSON backup can be imported on another browser or computer to move the workspace.

Running it yourself

LinearIsDead is a Next.js 15 and React 19 app written in TypeScript. The issue logic is a set of pure functions in lib/linear/model.ts with unit tests, and Playwright scripts in scripts/ drive the real interface with mouse and keyboard. To try it locally, run npm install and npm run dev, then open http://localhost:3000/linearisdead. Sign-in uses a shared Firebase project (Google or email and password); without its environment variables, a demo account works in development or with DEMO_MODE=1.

Limitations

  • The workspace is stored in your browser's local storage. Teammates you add are names on issues, not people logging into the same workspace, and nothing syncs between devices.
  • Because of that, the Inbox and notifications only reflect changes made in your own copy.
  • No integrations with GitHub, Slack or other tools, and no code review, AI agent, insights or SLAs.
  • It can't import Linear's CSV export; the importer only accepts LinearIsDead JSON backups.

FAQ

Can a whole team use one LinearIsDead workspace?

Not yet. Each browser holds its own workspace. You can pass a JSON backup around, but there is no live shared workspace.

Do I need to sign up?

No. You can use it as a guest, and the changelog says your work comes with you if you sign in later.

Are the keyboard shortcuts the same as Linear's?

Many are: C to create, J/K to move, S, P, A and L for status, priority, assignee and labels, ⌘K for the command menu. Press ? to see the full list.

How do I avoid losing data?

Download a JSON backup from Settings › Import / export regularly, especially before clearing browser data or changing computers.

Is it really free?

Yes. There are no paid plans, and the source is Apache-2.0.
