Free DocuSign alternative: DocuSignIsDead

Last reviewed October 26, 2026 · License: Apache-2.0 · Source on GitHub

DocuSignIsDead is a free, open-source tool for sending PDFs out for signature. You upload a document, place signature and other fields for each recipient, and send private signing links. When everyone has signed, you get a flattened PDF with a certificate page that records who did what and when.

What DocuSign does, and what DocuSignIsDead covers

DocuSign eSignature is the familiar "envelope" workflow: you prepare a document, add recipients, tag where each one signs, and track the envelope until it's complete. Beyond that, DocuSign offers identity verification, advanced and qualified signatures for regulated uses, bulk sending, payment collection, a large integration catalogue and a developer API. Its plans are priced per user and limit how many envelopes you can send.

DocuSignIsDead covers the basic envelope workflow. You can upload a PDF of up to 4 MB and 60 pages, start from a sample, or reuse a template with placeholder roles and fields. Each document can have up to ten recipients, each set as Signer, CC or Needs to view. You can put recipients in order so the second signer only gets access after the first finishes, or let everyone sign at once. Set a subject, message, expiry date and a reminder interval, then place signature, initials, date, text and checkbox fields, dragging and resizing them on the page.

Signers first agree to an electronic-records disclosure, then are guided through required fields. They can type or draw a signature, save progress and come back later, or decline. The finished PDF has the signatures flattened into the pages, plus a certificate listing consent, recipients, timestamps, a hash of the original document and the full activity history. On your side there are folders, search, status and date filters, void and delete, saved contacts, sending defaults and a simple reports page based on real events.

What it costs

As of October 2026, DocuSign's eSignature pricing page lists Personal at $11 a month ($132 a year) with 5 envelopes a month, Standard at $30 per user per month and Business Pro at $45 per user per month, both billed annually with 100 envelopes per user per year. Larger plans are quoted by sales. A three-person team on Standard pays $1,080 a year.

The hosted DocuSignIsDead is free and has no envelope counter. Self-hosting costs your own hosting and Firebase usage, plus Resend if you want the app to send email.

How to switch from DocuSign

  1. Download completed agreements and their certificates from DocuSign and store them somewhere you control. Nothing is imported, and old envelopes stay in your DocuSign account.
  2. Let envelopes that are already out for signature finish in DocuSign, or void them there and resend from the new tool.
  3. For each document you send often, upload the PDF to Templates, add placeholder roles such as "Client" and "Company", and place their fields.
  4. Add frequent recipients under Contacts and set your default subject, message and reminder interval in Settings.
  5. Send a test to yourself, sign it on a phone and a laptop, and check the completed PDF and certificate.
  6. If you self-host and want email delivery, configure Resend. Otherwise copy each signer's private link and send it yourself.

Running it yourself

The app is built with Next.js and uses Firebase Authentication and Firestore for durable storage. Without Firebase it falls back to local JSON files, which only suit a single development process. It needs Node 24.12 or later. Run npm install and npm run dev, then open http://localhost:3000/docusignisdead. Put settings in an ignored .env.local: the Firebase keys, AUTH_SECRET, and optionally RESEND_API_KEY, EMAIL_FROM and APP_URL for email. npm test, npm run lint and npm run typecheck run the checks, and there is a browser test suite for desktop and phone widths.

Limitations

  • Signatures are simple electronic signatures with an audit certificate. There is no identity verification and no cryptographic signing of the PDF.
  • Reminders are sent by hand once the interval passes; there are no automatic reminders.
  • No bulk send, in-person signing, payments, conditional fields or public API.
  • PDF only, with size and page limits. Typed signatures use a standard PDF font, so some characters need a drawn signature instead.
  • The project's parity report notes that live email and sign-in checks against real accounts are still outstanding.

FAQ

Are these signatures legally valid?

Simple electronic signatures with consent and an audit trail are accepted for many everyday agreements in many countries. Some documents need advanced or qualified signatures, a notary or wet ink. Check the rules that apply to your document; this page isn't legal advice.

Do signers need an account?

No. Each signer uses a private link. With sequential routing, a link only works once it's that person's turn.

Can I send Word documents?

Not directly. Export the file to PDF first, then upload it.

What does the finished document contain?

The original pages with signatures and field values flattened in, followed by a certificate showing consent, each recipient, timestamps, a hash of the original file and the activity history.

What happens if email isn't set up?

The app shows that delivery is unavailable and gives you a private link for each recipient to share however you like.
