Free Superhuman alternative: SuperhumanIsDead

Last reviewed October 26, 2026 · License: MIT · Source on GitHub

SuperhumanIsDead is a free, open-source desktop email client for Gmail that copies Superhuman's keyboard-driven way of working: a split inbox, single-key triage, snooze, send later and AI-written drafts. It runs on your Mac with no server of its own, and it talks to Gmail and your chosen AI provider using credentials you create yourself.

What Superhuman does, and what SuperhumanIsDead covers

Superhuman made its name as an email app you drive almost entirely from the keyboard. You move through conversations with j and k, clear them with e, snooze them with h, and reach every other command through a ⌘K palette. Around that core it adds split inboxes, reminders, scheduled sending, snippets, a calendar pane and, more recently, AI writing and summaries. Mail is now sold as part of a wider Superhuman suite that also includes Grammarly, Docs and the Go assistant.

SuperhumanIsDead rebuilds the Mail part of that experience as an Electron app written in TypeScript and React. The shortcut map follows Superhuman's closely, including the g navigation chords, ⇧E to un-archive, # for trash, inline ;name snippets and ⌘⇧L for send later. The Important / Other split uses Gmail's own categories, and an optional "Sort this list with AI" command reclassifies the loaded page and remembers your corrections on your machine.

The AI features (summarize a thread, draft a reply, write from a prompt, ask questions about your mail) work with Anthropic's API or any OpenAI-compatible endpoint, which includes OpenAI, xAI, OpenRouter and a local model served by Ollama or LM Studio. Without a key, every non-AI feature still works.

What it costs

As of October 2026, Superhuman's plans page includes Mail starting with the Business plan, at $33 per member per month billed annually or $40 billed monthly. The Free and Pro tiers cover Grammarly, Docs and Go but not Mail. Enterprise is priced on request.

SuperhumanIsDead costs nothing to download or use. The only possible running cost is AI: if you plug in a paid API key, your provider bills you per request, usually a small amount for occasional summaries and drafts. Pointing it at a local model costs nothing beyond your own hardware.

How to switch from Superhuman

  1. Install Node 22 and npm on your Mac, clone the repository and run ./scripts/setup.sh. Start the app with npm run dev, or build a disk image with npm run dist:mac. The README documents building from source rather than linking a prebuilt, notarized download.
  2. Click "Try the sample inbox" first if you want to learn the shortcuts on fake mail before connecting your account.
  3. Create your own Google OAuth client: make a project in Google Cloud Console, enable the Gmail API, configure an External consent screen with the gmail.modify scope, add your address as a test user, and create a "Desktop app" client ID. The calendar features also request the calendar.events scope, so enable the Google Calendar API in the same project if you want them.
  4. Paste the client ID and secret into the setup screen and sign in. Google will warn that the app is unverified, because it is your own test app.
  5. Optionally add an AI key in setup. Nothing needs importing: your mail, labels and drafts already live in Gmail. Snippets and snoozes you created in Superhuman have to be recreated.

Running it yourself

The code is split into an Electron main process (OAuth loopback sign-in, encrypted settings, Gmail and AI proxies, the snooze and send-later scheduler), a sandboxed preload bridge, pure shared modules with unit tests, and the React interface. Run npm test and npm run typecheck to check a change. To sign and notarize your own build, set CSC_NAME or CSC_LINK before npm run dist:mac.

Tokens and API keys are encrypted with the macOS keychain through Electron's safeStorage. Mail goes only to Google, and to your AI provider when you trigger an AI action. Message bodies render in a sandboxed frame with remote images blocked.

Limitations

  • Gmail only. There is no Outlook, iCloud or IMAP support.
  • Mac only, with no mobile or web client, and builds are unsigned unless you add your own Apple signing identity.
  • Snooze, reminders and send later run inside the app, so they fire only while it is open.
  • Google OAuth clients left in "Testing" mode issue refresh tokens that expire after about a week, so expect to sign in again periodically.
  • No shared team features, CRM panels or admin controls.

FAQ

Do I need a Superhuman account?

No. The app connects straight to your Gmail account using an OAuth client you create in Google Cloud.

Does my email pass through a SuperhumanIsDead server?

No. There is no project server. The app on your Mac calls Gmail directly, and calls your AI provider only when you ask for an AI action.

Can I use it without AI?

Yes. Leave the key blank and everything except summaries, drafts, Ask AI and AI sorting works normally.

Can I run the AI part locally?

Yes. Choose the OpenAI-compatible provider and point the base URL at a local server such as Ollama.

Why does Google call the app unverified?

Because the OAuth client belongs to you and hasn't been through Google's review. That is expected for a personal client.
