Free Miro alternative: MiroIsDead

Last reviewed October 26, 2026 · License: Apache-2.0 · Source on GitHub

MiroIsDead is a free, open-source online whiteboard with an infinite canvas, sticky notes, shapes, connectors, frames, comments and workshop tools like voting and a timer. Signed-in users' boards are saved to the server and can be shared by link. Live collaboration works peer to peer and doesn't connect on every network.

What Miro does, and what MiroIsDead covers

Miro is a shared visual workspace. Teams use its infinite canvas for brainstorming, workshops, retrospectives, flowcharts and planning, and it has grown to include docs, tables, slides, diagramming shape packs, AI features, video calls and many integrations, with admin and security controls on higher plans.

MiroIsDead focuses on the whiteboard itself. You pan and zoom freely (10% to 600%), with a dotted grid and a minimap. You can place sticky notes in eight colors whose text shrinks to fit, five basic shapes, text, freehand pen strokes, and frames whose contents move with them. Connectors can be elbowed, straight or curved, stay attached to shapes as you move them, and take labels and arrowheads. Selecting a sticky shows quick-create dots for adding a connected neighbor, and Tab chains new stickies. Smart guides help alignment, and a floating toolbar handles align, distribute and layering for multi-selections. Images can be uploaded, pasted or dropped in; they are compressed and stored inside the board.

For workshops it includes comment threads you can resolve, emoji reactions, a countdown timer, dot voting with a per-person budget, private mode for hidden stickies, and a shared board note. Twelve templates cover common formats such as brainstorms, retrospectives, flowcharts, SWOT, OKRs and user story maps.

What it costs

As of October 2026, Miro's pricing page lists Free, Starter at $8 per member per month and Business at $20 per member per month (both billed annually; Miro says annual billing saves 20% over monthly), and Enterprise with custom pricing for 30 or more members. The Free plan lets you create boards but keeps only three editable, limits exports to low resolution, and leaves out private board sharing and facilitation tools such as voting and the timer.

MiroIsDead is free at yourappisdead.com/miroisdead, with no board limit and no feature tiers. Self-hosting costs whatever your hosting does. Boards are stored in Firestore, whose free quota covers light use, and live sessions travel directly between browsers, so there is no real-time server to pay for.

How to switch from Miro

  1. Decide which Miro boards you still use. Archive the rest by exporting them from Miro as an image or PDF.
  2. Sign in to MiroIsDead. Signing in matters: boards made with the demo account stay in that browser only.
  3. Create a board, either blank or from a template that matches the Miro board's purpose.
  4. Rebuild the content. Paste in the exported Miro image as a reference layer if that helps, then redraw stickies, shapes and connectors on top, and delete the reference when you're done.
  5. Open Share, set "Anyone with the link" to view or edit, and send the link to your team yourself, since no invitation emails are sent.
  6. Download a JSON board backup now and then. It can be imported again from the boards list.

Running it yourself

MiroIsDead is a Next.js 15 and React 19 app in strict TypeScript, with its own SVG canvas engine in lib/canvas that handles the document model, undo history, connector routing, hit testing and snapping. Run npm install and npm run dev, then open http://localhost:3000/miroisdead. npm test runs unit tests and npm run e2e runs Playwright tests. Without the Firebase environment variables (see .env.example), the login page offers only the demo account. Live collaboration also needs the miroisdead_live rules from firestore.rules added to your Firebase project.

Limitations

  • Live collaboration is a direct browser-to-browser connection with no relay fallback, and the project notes that roughly one network in ten can't connect this way. Simultaneous edits are resolved by "last writer wins".
  • Users who aren't signed in only sync between tabs in the same browser.
  • Each board is stored as one document capped at 1 MiB, so image-heavy boards hit a limit; the app warns at about 700 KB.
  • No docs, tables or slides formats, no GIF packs, no Mermaid import, and limited touch gestures beyond pinch and pan.
  • The activity and call buttons in the board header are placeholders, and the AI bar opens a command palette rather than generating content.
  • No invitation emails; you share links yourself.

FAQ

Can several people edit a board at once?

Yes, if they're signed in and their networks allow a direct peer-to-peer connection. You'll see each other's cursors and edits. On some restrictive networks the connection fails.

Can I share a board with someone who has no account?

Yes. Set link access to "Can view" or "Can edit" and anyone with the link can open it, view-only or as a guest editor.

Can I import my Miro boards?

No. MiroIsDead imports only its own JSON backups. You'll need to rebuild boards, using an exported image as a guide.

How many boards can I have?

The app doesn't limit the number of boards. Each board has a size limit of about 1 MiB because of how it is stored.

Does it work on a tablet?

Pinch to zoom and panning work, but other touch gestures are limited, so a mouse or trackpad is the better experience.
