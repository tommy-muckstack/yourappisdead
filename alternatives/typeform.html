Free Typeform alternative: TypeformIsDead

Last reviewed October 26, 2026 · License: Apache-2.0 · Source on GitHub

TypeformIsDead is a free, open-source form builder that shows respondents one question at a time. It has ten question types, logic jumps, a results view with charts and NPS, and CSV export. It covers the everyday survey, feedback and lead-capture jobs, but many of Typeform's advanced question types, themes and integrations are not built yet.

What Typeform does, and what TypeformIsDead covers

Typeform is known for conversational forms: one large question on screen, keyboard shortcuts, and a progress bar, which tends to feel lighter than a long page of fields. Behind that it offers dozens of question types, branching logic with scores and variables, themes, integrations with other tools, and analytics on where people drop off. Paid plans are mostly separated by how many responses you can collect each month and how many people can work in the account.

TypeformIsDead copies the format and the core workflow. The builder supports short text, long text, email, number, multiple choice (with multi-select and an "Other" option), yes/no, star rating, a 0 to 10 opinion scale, date, and statement screens. You can reorder, duplicate and delete questions, add a welcome screen and an ending, and see a live preview while you edit. Changes save automatically. Logic jumps can move a respondent forward based on the current answer, using conditions such as "is", "contains" or "greater than".

Respondents open a public link at /f/<id> and answer one question at a time with Enter, letter keys or Y/N. The server checks each submission against the form and the path the respondent actually took, and rejects unknown fields. Results show responses, views, completion rate, average time, a chart per question, an NPS score for opinion scales, and a table you can export to CSV. The export escapes values so spreadsheet formulas in answers can't run.

There are four starting templates (blank, customer feedback, lead capture and event RSVP) and a simple prompt box that builds a starter form from a short description. That box follows fixed rules rather than calling an AI model, and the app labels it accordingly.

What it costs

As of October 2026, Typeform's pricing page lists Basic at $28 a month billed yearly ($39 billed monthly) with 100 responses a month and one user, Plus at $56 a month yearly ($79 monthly) with 1,000 responses and three users, and Business at $91 a month yearly ($129 monthly) with 10,000 responses and five users. There is also a free plan, specialised Growth and Talent plans, and custom Enterprise pricing. When we checked, the page's comparison table showed slightly different figures from its plan cards, so confirm the number for the plan you need.

The hosted TypeformIsDead is free, with no response cap built into the app. Self-hosting costs whatever your host and database charge; the project is designed to run on Vercel with Firestore.

How to switch from Typeform

  1. Download your existing responses from Typeform as a CSV so you keep your history. There is no importer for forms or answers.
  2. Open TypeformIsDead and start from a template or a blank form. Add the questions again, choosing the closest of the ten types. Questions that rely on file upload, payment, matrix or ranking need a rethink.
  3. Re-create your logic jumps. Targets can only point forward, so order questions so that branches skip ahead.
  4. Write your welcome and ending text, then preview the form and submit a test response. Check it appears under Results.
  5. From the Share tab, copy the public link or the iframe snippet and replace your old Typeform links and embeds.
  6. Since there are no integrations or email alerts yet, plan to check Results or export a CSV on a schedule.

Running it yourself

TypeformIsDead is a Next.js app. Sign-in uses Firebase Authentication. Forms and responses are stored in Firestore when FIREBASE_SERVICE_ACCOUNT_JSON is set, and in JSON files under .data/ otherwise, which is fine on your own machine but not on a serverless host with a temporary disk. Locally, run npm install and npm run dev, then open http://localhost:3000/typeformisdead. A demo account is available outside production. npm test runs the unit tests and npm run typecheck checks types.

Limitations

  • Only ten question types. No file upload, payment, matrix, ranking, picture choice, dropdown, phone, address or signature questions.
  • No themes, fonts or custom colors on the form.
  • No webhooks, integrations or email notifications for new responses.
  • Logic is forward-only and has no scores or variables. Hidden fields and URL prefill aren't supported.
  • Edits go live immediately; there's no separate draft version of a published form.
  • Anyone with the link can submit, and there is no rate limiting beyond size limits.
  • The project's own parity report lists many interface details as unverified or incomplete, so expect rough edges.

FAQ

Is there a limit on responses?

The app doesn't impose one, and a fixed storage cap was removed. Real limits come from the storage behind the deployment.

Can I import my Typeform forms?

No. You rebuild forms by hand and keep old answers by exporting them from Typeform as CSV.

Can I run an NPS survey?

Yes. The 0 to 10 opinion scale calculates an NPS score in Results, and the feedback template branches unhappy customers to a follow-up question.

Will I get an email when someone responds?

Not yet. Notifications and webhooks are on the list of missing features, so check the Results tab or export a CSV.

Does the prompt builder use AI?

No. It applies fixed rules to build lead, feedback or RSVP forms, or a generic starter form, which you then edit.
