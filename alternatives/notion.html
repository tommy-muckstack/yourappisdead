Free Notion alternative: NotionIsDead

Last reviewed October 26, 2026 · License: Apache-2.0 · Source on GitHub

NotionIsDead is a free, open-source writing workspace with nested pages, a block editor with a slash menu, page links with backlinks, and Markdown import and export. It covers the personal notes-and-wiki side of Notion, not the team and database side. Your pages are stored in your browser, so it suits one person on one device best.

What Notion does, and what NotionIsDead covers

Notion combines a document editor, a page hierarchy and relational databases in one product, then adds team features on top: shared teamspaces, permissions, comments, real-time editing, integrations and an AI assistant. Many people use only a small part of that: a tree of pages where they keep notes, meeting write-ups, reading lists and a personal wiki.

NotionIsDead targets that smaller part. You get a sidebar of pages that can nest as deep as you like, favorites, a recent-pages home screen, breadcrumbs, and a Trash you can restore from. Inside a page, every paragraph is a block. Typing / opens a menu of 11 writing blocks (text, three heading levels, bulleted and numbered lists, to-dos, quotes, callouts, code and dividers) plus a very simple inline database, and Markdown shortcuts such as # , - and [] convert a line as you type. Double-bracket links like [[Project plan]] connect pages, and each page shows what links back to it. ⌘K searches titles and body text across the workspace.

That inline database is deliberately small: a titled list of rows, each with a name and one of three statuses (Not started, In progress, Done), shown as a table or as a kanban board. There are no custom properties, relations or formulas, and the filter and sort icons in its toolbar don't do anything yet. If your Notion setup depends on real databases or on collaborators editing the same page, this is not a replacement yet.

What it costs

As of October 2026, Notion's pricing page lists a Free plan, Plus at $10 per member per month and Business at $20 per member per month, with Enterprise priced on request. Notion says paying yearly saves up to 20%, so month-to-month billing costs more than those headline figures. The Free plan is unlimited for a single member, but workspaces with several members get a limited block allowance, uploads are capped at 5 MB per file, and page history goes back 7 days. Notion's AI agent features sit on the Business plan and above.

NotionIsDead costs nothing to use at yourappisdead.com/notionisdead, and there are no plan tiers. If you run it yourself, the cost is whatever your hosting costs; because pages are kept in the browser, the server does very little work.

How to switch from Notion

  1. In Notion, open the page or workspace settings and choose Export with the Markdown & CSV format. Include subpages if you want the whole tree. Notion gives you a .zip file.
  2. Unzip it on your computer. Each page becomes a .md file; database rows come out as CSV, which NotionIsDead can't import (consider AirtableIsDead for those).
  3. Open NotionIsDead and import each .md file you want to keep. Each import creates a new page with headings, lists, to-dos, quotes and code turned into blocks.
  4. Rebuild the hierarchy by using Move to on each page, and re-create any links between pages with [[double brackets]].
  5. Images and attachments won't come across. Keep the unzipped export folder somewhere safe as an archive.
  6. Get into the habit of exporting important pages to Markdown, since nothing is backed up off your device.

Running it yourself

The app is a Next.js 15 and React 19 project written in TypeScript. Clone the repository, run npm install, then npm run dev and open http://localhost:3000/notionisdead. npm test runs the unit tests, which include a set of documents used to check that converting blocks to Markdown and back doesn't lose anything. Sign-in uses Firebase (email and password or Google); without the Firebase environment variables the login page says sign-in is not configured, and a demo account is available in development or when DEMO_MODE=1 is set.

Limitations

  • Pages live in your browser's local storage. Clearing site data, switching browsers or moving to another computer means starting over unless you exported first.
  • There is a Share button and a copy-link button, but because pages aren't stored on a server, a copied link won't show your page to anyone else.
  • No images, embeds, comments or AI, and the inline database has only a name and a status per row.
  • Lists can't be indented, and you reorder blocks with ⌘⇧↑/⌘⇧↓ or the block menu rather than by dragging.

FAQ

Is NotionIsDead really free?

Yes. There are no paid plans, and the code is under the Apache-2.0 license, so you can also run or modify your own copy.

Can my team use it together?

Not today. There is no shared workspace or live editing, and pages are stored per browser. It works best as a personal notebook.

Will my Notion databases come across?

No. NotionIsDead's inline database only tracks a name and a status per row, and it can't import CSV. Notion exports databases as CSV files, which you could load into a spreadsheet or into AirtableIsDead instead.

How do I back up my pages?

Export each page to Markdown from the page menu. The files are plain text, so any editor or Git repository can hold them.

Does it work offline?

Pages are read from and saved to your browser, but the app itself is served from the web, so you need a connection to load it.
