Free Airtable alternative: AirtableIsDead

Last reviewed October 26, 2026 · License: Apache-2.0 · Source on GitHub

AirtableIsDead is a free, open-source spreadsheet-database with typed fields, saved grid and kanban views, filters, sorts and CSV import and export. It handles the "smarter spreadsheet" side of Airtable for one person. It doesn't have linked records, formulas, automations or sharing, and your data stays in your browser.

What Airtable does, and what AirtableIsDead covers

Airtable looks like a spreadsheet but behaves like a database: each column has a type, records can link to records in other tables, and the same data can be shown as a grid, kanban board, calendar, gallery or form. On top of that it offers automations, interfaces for non-technical users, an API, integrations and AI features, with team permissions throughout.

AirtableIsDead covers the core you touch every day when you track things in a table. A base can hold several tables. Fields come in eight types: single-line text, long text, number, checkbox, single select, multiple select, date and URL, and the grid checks what you type against the field type. You move and edit with the keyboard (arrow keys, Enter, Tab, Escape), add, rename, retype or delete fields, and recolor select options. Any record expands into a form-style panel for editing.

Views are where it gets useful. Each table can have several saved grid and kanban views, and every view keeps its own filters (combined with "and" or "or"), multi-level sort, hidden fields and search. Kanban views stack cards by any select field, and you drag cards between stacks to change the value. A summary footer under the grid shows counts, and for numbers the sum, average, minimum and maximum.

What it costs

As of October 2026, Airtable's pricing page lists a Free plan aimed at individuals and very small teams, Team at $20 per seat per month and Business at $45 per seat per month, both billed annually, and Enterprise Scale with custom pricing. Paid plans raise the limits on records, storage and automation runs and add features such as more view types and permissions; check the page for the exact limits of each tier, which change from time to time.

AirtableIsDead is free at yourappisdead.com/airtableisdead, with no seats or plan limits built into the app. If you host your own copy, you pay only for your hosting. The practical ceiling is your browser's local storage space, since that is where the data is kept.

How to switch from Airtable

  1. In Airtable, open the table you want to move and pick a grid view that shows every field (unhide anything hidden).
  2. From the view's menu, choose Download CSV. Repeat for each table.
  3. Open AirtableIsDead and use Import CSV. Each file becomes a new table, and the importer guesses field types from the values.
  4. Check each field's type and change any that were guessed wrong. Select fields need their options and colors reviewed.
  5. Linked-record columns arrive as plain text, and attachment columns arrive as text links at most, so decide whether you still need them.
  6. Re-create your views: add a kanban view for each pipeline, and set the filters, sorts and hidden fields you used before.
  7. Export important views back to CSV every so often as a backup.

Running it yourself

AirtableIsDead is a Next.js 15 and React 19 app in TypeScript. The table logic lives in plain functions in lib/airtable/model.ts, covered by unit tests. To run it locally, clone the repository, run npm install and npm run dev, then open http://localhost:3000/airtableisdead. npm test runs the tests, and npm run build && npm run shots runs an end-to-end smoke test with Playwright. Sign-in uses Firebase; without its environment variables, a demo account is available in development or with DEMO_MODE=1.

Limitations

  • Data is saved in your browser's local storage for your account. It doesn't sync across devices and can't be shared with teammates.
  • There is one base per account, so use separate tables rather than separate bases.
  • No linked records, lookups, rollups or formulas, which rules it out for relational setups such as CRMs with linked contacts and companies.
  • Only grid and kanban views; no calendar, gallery, timeline or form.
  • No attachments, automations, API or integrations.

FAQ

Can I import my Airtable base directly?

Not as a whole base. Export each table from Airtable as CSV and import the files one at a time. Field types are guessed from the data and can be changed afterwards.

Is there a record limit?

The app doesn't set one. Because everything is stored in the browser, very large tables will eventually hit the browser's storage limit and may slow down.

Can I collaborate with my team?

No. There's no sharing or live editing yet. Each person's data stays in their own browser.

What happens if I clear my browser data?

Your tables are deleted along with it. Export the views you care about to CSV before you clear anything or switch computers.

Can I change the code?

Yes. It is licensed under Apache-2.0, so you can fork it, modify it and run your own version.
