What this site is

YourAppIsDead is a directory of free, open-source replacements for software that people usually pay for every month: scheduling links, docs and wikis, kanban boards, e-signatures, link shorteners, form builders, screen recorders and more. Each app on this page is a separate open-source project with its own public repository. You can use the hosted version here for free, read the code, or run your own copy.

None of these apps is a one-for-one copy of the product it replaces. Each one covers the core job well enough for an individual or a small team, and each has gaps. Every app has a full write-up that says, in plain language, what it does, how its features compare with the paid product, what the paid product currently costs, how to move your data over, how to run it yourself, and what it can't do yet. Start with the write-up if you're deciding whether to switch: the list of all alternatives is the quickest way in.

How apps are chosen

Apps get built when a subscription is popular, its core job is well understood, and the free version can be genuinely useful rather than a demo. Anyone can request one with the form below, and anyone can build one. The guide to how the apps are built covers the rules every project follows: original artwork and code only, a permissive license, a shared sign-in, and working on phones and with a keyboard.

Should you switch?

Sometimes, not always. Free tools save the most when you pay per seat for features you barely use. Paid products are still the better choice when you need vendor support, compliance paperwork, or integrations these young projects don't have yet. The guides on auditing your subscriptions, judging an open-source app and self-hosting walk through those trade-offs.

The site is maintained by @tommy-muckstack and open-source contributors. It's free to use and supported by ads. YourAppIsDead isn't affiliated with any company whose product is named here.
