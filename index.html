    Everything here is open source.

    YourAppIsDead is a marketplace of open-source SaaS replacements. Every app has a public repo under a permissive license, and so does this site. Read the code, run it yourself, fork it, or send a pull request.

    • 01

      Build a new clone

      Pick a subscription people are tired of paying for, build the free version, and list it here. The contributing guide covers naming, licensing and what a listing needs.

      Read the contributing guide
    • 02

      Improve an existing app

      Every tile links to its repo. Fix a bug, add the feature you miss from the paid version, or improve the docs. Issues and pull requests are open on all of them.

      Browse all repos
    • 03

      Improve this site

      The marketplace itself is a small static site with no build step. Add a listing to apps.json, fix copy, or make the graveyard better.
